
# Library Management App

Python aur Tkinter UI par aadharit ek simple aur aasaan Library Management Application. Yeh app college project ke liye design ki gayi hai aur Pydroid 3 (Android) par bhi bilkul smoothly chalti hai.

## Features
- Home Page: Library ke live statistics (Total, Available aur Issued books) dikhata hai.
- Add Book: Nayi kitabein library database mein jodne ke liye.
- Search Book: Title, Author ya Genre ke hisab se kitab dhoondhne ke liye.
- Issue Book: Kitab ko kisi ke naam par issue karne ke liye.
- Return Book: Issued kitab ko wapas jama karne ke liye.
- AI Book Recommendation: Aapke pasandida genre ke hisab se kitab suggest karne ke liye.

## Tech Stack
- Language: Python 3
- UI Framework: Tkinter (Python's Built-in GUI)

## Kaise Chalayein (How to Run)
Is project ko chalane ke liye kisi alag library (jaise Streamlit ya pip requirements) ki zaroorat nahi hai.

1. app.py file ko download ya copy karein.
2. Apne PC ya Mobile (Pydroid 3 app) mein Python install karein.
3. Code ko run karein:
   ```bash
   python app.py
   ```
